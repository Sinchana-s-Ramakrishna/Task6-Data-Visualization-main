🎯 Objective

The goal of this task is to analyze and visualize data using Python libraries like pandas and matplotlib to discover patterns, trends, and relationships in the dataset.

Dataset used: World Happiness Report

🛠 Tools & Technologies Used

Python 🐍

Google Colab

Pandas (for data handling)

Matplotlib (for visualization)

📈 Visualizations Created
1️⃣ Bar Chart – Top 10 Happiest Countries

This chart displays the top 10 countries with the highest happiness scores.
It helps compare happiness levels across leading nations.

Insight: The top countries have very similar happiness scores, indicating consistently high living standards and well-being.

2️⃣ Line Chart – Happiness Score Comparison (Top 10 Countries)

This line chart shows the variation in happiness scores among the top 10 countries.

Insight: The differences between the happiest countries are small, showing that they maintain similarly high levels of life satisfaction.

3️⃣ Histogram – Distribution of Happiness Scores

This histogram shows how happiness scores are distributed across all countries in the dataset.

Insight: Most countries fall into the mid-range of happiness scores, with only a few countries having very high or very low happiness levels.

4️⃣ Scatter Plot – GDP vs Happiness Score

This scatter plot shows the relationship between Log GDP per Capita and Happiness Score.

Insight: There is a positive correlation between GDP and happiness, meaning countries with higher income levels tend to report higher life satisfaction.

📌 Key Learnings

Different charts are used for different types of analysis

Bar charts help in category comparison

Line charts help show trends or patterns

Histograms show data distribution and outliers

Scatter plots help identify relationships between variables
